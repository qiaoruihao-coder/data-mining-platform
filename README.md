# AI 家装平台 · 数据挖掘大作业

以家装需求、服务方匹配与履约管理为场景，结合住宅案例聚类和双向推荐的课程项目。此仓库保存桌面平台的当前源码快照及更新版答辩 PPT（2026-11-21）。

## 功能

- 业主端：需求澄清、案例推荐、服务方匹配、报价核对、排期与履约记录、评价和售后。
- 服务方端：需求大厅、基于本人历史订单的推荐、报价与订单管理；支持同城、自选城市和全国范围。
- 管理端：需求、服务方、评价与售后记录查看。
- 数据挖掘：案例多视图加权 K-means、需求聚类、历史偏好推荐；另保留离线分类和聚类实验。

## 本地启动

需要 Node.js >=20.19（建议22）和 npm。

```powershell
git clone https://github.com/qiaoruihao-coder/data-mining-platform.git
cd data-mining-platform/ai-home-platform
npm.cmd ci
Copy-Item .env.example .env
npm.cmd run db:setup
npm.cmd run dev
```

访问 http://localhost:3000 。macOS/Linux 将 `npm.cmd` 换为 `npm`，复制命令换为 `cp .env.example .env`。已有配置不要覆盖。维护者用 `npm run owner:create` 创建业主账号；不提供真实凭据。案例页通过 `/api/cases` 使用附带快照，离线实验依赖见 `experiments/mining/requirements.txt`。

## 演示边界

AI澄清默认mock，可通过服务端环境变量接入模型；照片上传与真实图像分析是不同功能，真实分析尚未完成。付款是模拟流程。公开服务方和演示历史含合成数据，不能当作真实业务成交。固定示例两份报价已知小计为12,000元和13,000元，其中清运待确认、地面单位不同、成品保护列项有差异，不能直接宣称最终最低价。

本地业务数据库、账号、用户照片、密钥、依赖和缓存未上传；数据库里的临时演示订单不会随源码自动迁移。演示种子和脚本可供复现，但不能将脚本清单当作已完成的真实交易。
