# AI 家装平台数据挖掘项目

课程项目，包含家装平台源码快照、数据挖掘实验和答辩 PPT。平台覆盖装修需求、服务方匹配和订单履约。

## 公网演示入口

[打开公网演示](https://causing-cross-specified-schools.trycloudflare.com)

公网地址为临时隧道，演示电脑和隧道需保持运行，重启后地址可能变化。演示使用合成数据和公开案例，不连接本地数据库，也未启用真实 AI 调用或演示登录。

### 校园网局域网测试入口

![校园网扫码访问](platform-campus-qr.png)

二维码打开当前电脑的 `http://10.99.214.65:3000`。手机和电脑需连接同一校园网，且电脑上的网站保持运行。校园网若限制设备互访，手机仍无法连接。IP 变化后需重新生成二维码；校外请使用上方公网演示。

## 功能

- 业主端：需求澄清、案例推荐、服务方匹配、报价和履约管理。
- 服务方端：需求大厅、订单推荐、报价与订单管理；可选同城、自选城市或全国服务范围。
- 管理端：查看需求、服务方、评价与售后记录。
- 数据挖掘：住宅案例多视图加权 K-means、需求聚类、历史偏好推荐，以及离线分类和聚类实验。

## 本地启动

需要 Node.js 20.19 或更高版本，建议使用 22，并安装 npm。

```powershell
git clone https://github.com/qiaoruihao-coder/data-mining-platform.git
cd data-mining-platform/ai-home-platform
npm.cmd ci
Copy-Item .env.example .env
npm.cmd run db:setup
npm.cmd run dev
```

访问 `http://localhost:3000`。macOS/Linux 用户将 `npm.cmd` 换为 `npm`，并用 `cp .env.example .env` 复制环境文件。已有 `.env` 不要覆盖。维护者可运行 `npm run owner:create` 创建业主账号；仓库不提供真实凭据。案例页面通过 `/api/cases` 读取快照。离线实验依赖见 `experiments/mining/requirements.txt`。

## 演示边界

需求澄清默认使用 mock，可通过服务端环境变量接入模型。真实图像分析尚未实现，付款仅为模拟流程。公开服务方信息和演示历史含合成数据，不代表真实成交。

示例中的两份报价小计为 12,000 元和 13,000 元。清运费用待确认，地面单位和成品保护项目也不同，不能据此判定最终报价高低。

本地数据库、账号、用户照片、密钥、依赖和缓存未上传。源码不会迁移临时演示订单。种子数据和脚本用于复现实验，不代表真实交易。
