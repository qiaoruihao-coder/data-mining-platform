## 准备隔离数据

先停止本工作目录的 dev/start 服务，避免与 build 同时写入 `.next`。在新的 PowerShell 终端中进入已有项目；首次安装或锁文件有变化时先运行 `npm.cmd ci`。不要覆盖原 `.env`、重置或删除已有数据库。

```powershell
$env:DATABASE_URL = "file:./demo-$([guid]::NewGuid().ToString('N')).db"
$env:AI_MODE = "mock"
$env:DEMO_AUTH_ENABLED = "true"
Write-Output $env:DATABASE_URL
npm.cmd run db:setup
if ($LASTEXITCODE -ne 0) { throw "隔离库准备失败" }
```

只看固定样例可直接启动。需要完整写入链路时，在**同一终端、启动服务前**运行 `npm.cmd run owner:create`，交互建立新的合成业主账号；无默认密码，demo-owner 不能登录。密码只在交互提示中输入，不写入命令、脚本或截图。随后运行 `npm.cmd run dev`，在新的浏览器隐私窗口打开本机 `http://localhost:3000`，避免沿用其他数据库的旧会话。不要在另一个终端生成新的数据库名后创建账号，否则服务与账号会落在不同库。

## 合成账号的完整写入链路

1. 通过全局“业主登录”使用刚建立的合成账号，在需求澄清页核对草稿后发布非演示需求。保存成功来源 live，含义是数据实际保存；不表示 AI 已接通。
2. 点击“演示服务方登录”，在 `/provider` 打开该 published 需求并提交报价。报价来源 mock，重复/结果不确定时保留原幂等键先核实，不连续换键提交。需要纯服务方视角时先退出业主会话；双 cookie 的优先级由接口决定，角色导航不会切换认证身份。
3. 重新登录原业主，打开 `/owner/quotes/<需求ID>`，核对待定费用和来源后确认接受报价。打开 `/provider/orders` 验证实际接单，而不是把已提交报价视作接单。接受演示报价建立的接单仍是 mock。
4. 在 `/owner/project/<需求ID>` 创建首版手工排期；未开工时可确认修订并读取旧版本。按页面动作开工、依赖顺序逐工序完成，再确认整单完成。跳级、旧版本、未完成工序必须被拒绝；这些是业主确认，不是专业验收。
5. 在同一施工排期页 `/owner/project/<需求ID>` 上传本次专用的合成 JPEG/PNG：上传成功 live，检查结果 mock 并注明“未分析照片内容”。真实照片分析仍 501，不能展示为成功验收；不使用真实客户照片。
6. 完成后打开 `/owner/demand/<需求ID>` 评分并刷新读取；只允许本人实际完成的接单评价，来源沿用接单。也可在此创建售后工单：保存为 open，表示已记录，不表示已派单或解决。
7. 回到 `/owner/project/<需求ID>` 的最新排期视图，查看“履约记录”并点击“刷新记录”，核对动作、状态、记录时间、工序、版本和逐条来源；指定旧排期版本时不展示这块记录。记录来自本人 `GET /api/order/progress?demandId=…`，不代表专业验收或付款。退出业主后，受保护的接单、履约、评价和照片接口应拒绝。

## 自动验收与退出

按 Ctrl+C 停止演示服务，在同一隔离库终端运行：

```powershell
npm.cmd run check
if ($LASTEXITCODE -ne 0) { throw "check 失败" }
npm.cmd run build
if ($LASTEXITCODE -ne 0) { throw "build 失败" }
npm.cmd run scope -- --role D --base origin/main
if ($LASTEXITCODE -ne 0) { throw "scope 失败" }
node scripts/run-production-smoke.mjs
if ($LASTEXITCODE -ne 0) { throw "生产 HTTP 冒烟失败" }
```

runner 使用独立本机端口并停止自己创建的服务，子进程明确设置 AI_MODE=mock 和演示服务方开关。结束后关闭该终端，正常启动继续使用原 `.env`。

## 失败与尚未完成的验收

- 401：重新登录或退出失效会话后刷新；切换导航不能修复凭证。404 可能为无权访问，不猜测他人记录。409：刷新实际状态/版本后重新确认，不自动换版本重发。
- 501：明确标记未实现；503/网络失败：保留输入和来源，刷新核实，不假定写入一定未发生，也不回退模拟成功。任一查询范围内坏评价/关联可使整个目录 503，先核对隔离库数据，不隐藏失败。
- #161 已将 #160 读取器接入独立 `/api/match` API；共享生产冒烟检查正常接受报价后的实际非公开需求：匿名、其他业主和仅服务方均 404，所属业主仍可读。不能把这一接口的验证扩大为整个平台已完成权限审计。
- 真实需求澄清完整业务验收仍待完成；本机配置或单次供应商连通不等于完成验收。真实照片分析、生产服务方/管理员认证、支付/资金托管、专业验收、售后派单/解决与通知仍未交付。固定模拟付款仅为进程内状态演示。
