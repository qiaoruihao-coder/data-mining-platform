# B：业主明确确认接受报价

接入已合入 main 的 D 接单契约（PR #119）。本次只修改 B 私有页面、逻辑、测试及本记录；不申请新的公共字段，不修改依赖、数据库 schema 或其他角色模块。

## 行为与验收入口

在 `/owner/quotes/<本人需求ID>` 登录所属业主并读取报价。已发布需求的 submitted 报价可选择；固定演示、已接单需求、已有 accepted 报价及来源未知的报价无接受入口。先核对下方明细，再选择报价；选择及取消均不写入。确认区展示需求、报价和服务方编号、来源、已知费用小计、待定费用、预计天数，以及接受不代表最终价格、付款、法律合同或施工验收的说明。

只有“确认接受此报价”调用 `apiPost('/api/order', { demandId, quoteId, confirmed: true }, OrderSummary)`。响应须匹配所选需求、报价、服务方和逐条/整体来源。200 重放及 201 首次均成功；409 ORDER_ALREADY_EXISTS 显示“已接受其他报价，不能改选”；501 不当成功。503、网络错误、坏回执按结果不确定处理。

每次页面挂载最多发一次接受请求，同步锁阻止双击。提交中不执行焦点或手动刷新；请求结束立即重新读取需求和报价。结果区在读取失败时仍保留，后续“刷新报价”或“重新加载”只读核实，不自动重发。选择后刷新会作废旧确认；切换需求会重建页面状态。报价 accepted 与需求接单状态只使用服务端回读，不在客户端乐观伪造。无有效接单回执时，回读 accepted 仅说明报价状态已核实，不补造关系编号或历史订单。

- 390px 手机宽度实看确认区，无页面横向溢出；固定 demo-demand 页面没有接受按钮。浏览器测试账号、密码、数据库、截图均留在仓库外，不提交。

## 限制与来源

真实密码认证和持久化接单接口已接通；测试报价来自演示服务方，仍为 mock，AI_MODE=mock。故障注入只用于测试，没有运行时假成功或自动回退。每次提交后该页面仅提供读取核实；暂未提供同页面再次确认提交的恢复流程，不支持取消/改选、多服务方拆单、付款、合同签署或履约推进。

P1 可用工期及履约评分排序仍依赖 D 提供公共字段，不属于本次接单确认功能。实际操作系统标签切换与 bfcache 人工验收仍未完成。
