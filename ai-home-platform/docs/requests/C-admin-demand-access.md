# C：管理端需求读取范围与会话恢复

从 main `8899005` 开始，提交前快进同步至 `917b960`（包含 #101、#104、#107、#108）。本次只完成 `/admin` 和 `/admin/demand/[id]` 的访问说明及恢复入口，不增加管理员认证或全量查询。

## 问题与交付

管理端复用 `GET /api/demand` 与 `GET /api/demand/[id]`，此前 401/403 却提示完成“平台管理身份验证”或核实“平台管理权限”。当前没有这个登录入口；错误实际可能来自优先验证的业主凭证，失效时顶部业主登录栏又可能显示未登录而隐藏退出按钮。

- 看板说明未登录业主时仅返回已发布公开需求；有效业主登录时只返回本人所有状态的需求。统计仍只基于本次返回列表，不表示全平台数量。
- 详情说明已发布需求公开可读，其他状态仅所属业主可读。从工单进入、切换管理角色均不增加访问权限。两页说明登录、退出或身份变化后需手动刷新查询。
- 两页复用 C 既有 `demandAccessFailure` 与 `DemandAccessRecovery`。仅 `401 UNAUTHENTICATED` / `403 FORBIDDEN` 显示“退出业主会话并刷新页面”。用户操作前不会自动退出；401/403 的未知错误码、坏回执、404、501、503 和网络失败不显示此按钮。
- 继续由已有 `DELETE /api/auth/owner` 完成退出，公共 `OwnerSessionState` 校验且 `live + signed_out` 后才刷新整页。等待中防重复，失败保留提示并允许显式重试；501 与 mock 回执不等于退出成功，服务方演示会话独立保留。
- 加载和失败时不显示旧统计、旧列表或旧详情；只有需求接口明确返回 `404 DEMAND_NOT_FOUND` 才显示不存在或不可查看。退出后私有详情仍接受服务端授权判断，不回退演示需求。
