# C：管理端评价汇总筛选

基于 main `ee90b0e` 开始，交付前已同步 `161efb9`（A 的 #156），在 `/admin/provider-reviews` 补充公开目录内的关键词与评价样本筛选；不改变公共契约、接口、依赖或权限。

## 行为与验收

- 关键词按服务方名称、编号、城市分别匹配，去除首尾空白、忽略大小写，按字面连续文本匹配，不匹配标签或评分。
- 评价样本分为全部、已有评价（大于 0 条）、暂无样本（明确 0 条）和汇总未知（缺省/null）；不使用旧 rating，不把未知当成零样本或把零样本当作零分。
- 两项条件取交集，保留接口顺序、原均分/样本/计算时间及各维度来源；显示筛选数量与本次目录总量。无匹配与接口真实空目录区分。
- 清除筛选只清关键词和样本条件。页面内刷新及切换 live/mock 保留条件，按新响应筛选；离开或整页刷新后重置。切换来源/刷新期间清除旧结果，忽略旧请求迟到响应。
- 仍只请求 `GET /api/provider?performanceSource=live|mock`，统一使用公共 Provider、ProviderQuery、Source 和 API 客户端。先验证完整响应再筛选；加载、501、503、无授权和格式异常不显示成功或空匹配。
