# C：服务方评价汇总看板

基于 main `54bd490`，复用 D 已合入的评价汇总契约及公开目录接口。本次提供独立管理页面，不依赖待合入的服务方资料详情 PR #145。

## 本次交付

从 `/admin` 的“查看服务方评价汇总”进入 `/admin/provider-reviews`，查看公开目录内各服务方已完成接单的业主评价均分、样本数和计算时间，支持刷新及返回管理看板。

- 默认 live，可显式切换 mock；仅调用 `GET /api/provider?performanceSource=live|mock`，使用公共 `ProviderQuery`、`Provider`、`Source` 及 API 客户端，不在客户端计算或补造均分。
- 目录整体来源、各条基础资料来源和评价来源独立展示。基础资料缺来源显示未知；`performance` 缺失/null 显示“未提供评价汇总”，不等于无样本。
- 明确的 null/0 显示“暂无均分”和 0 条，少于 3 条提示样本少；不回退旧 `Provider.rating` 或另一来源，不做排名、平台总均分或信用判断。
- 重复服务方编号、评价来源与查询口径不符、坏 DTO/响应和网络错误均失败。401/403/404/501/503 不转成功，501 即使返回成功信封也仍报错。
- 切换来源或刷新立即移除旧统计，卸载后忽略迟到响应；失败显示重试入口。公开目录只读，不授予管理员身份或扩大数据权限。

## 模拟与未实现

公开目录仍是六个固定 mock 服务方。评价按持久化的 mock/live 来源分别统计，live 不代表已核实评论事实、真实身份或实际施工；没有样本时如实为空。

浏览器验收数据全部为隔离合成夹具：mock 报价通过演示服务方 HTTP 提交，live 报价仅为存储夹具；随后均经实际接受、开工、完成、评价 HTTP 链路生成样本，未直接改库伪造完工。同内容评价重放未增加样本数，合成 live 记录不代表接通生产服务方认证。

本次没有实现公开评价明细、审核/回复、时间趋势、排名、平台全量评价或管理员认证；这些不在现有公开汇总契约范围内，涉及共享接口需由 D 后续支持。
