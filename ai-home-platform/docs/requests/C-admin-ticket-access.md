# C：管理端工单会话恢复

基于 main `6a016ee`，本次只完善 `/admin/tickets` 的访问说明和业主会话错误恢复。

## 问题与交付

无参数 `GET /api/ticket` 目前返回固定模拟工单，但仍校验浏览器已有的业主凭证。失效凭证返回 401，账号角色变化返回 403；顶部业主状态可能显示未登录并隐藏退出按钮。此前工单页却提示完成尚不存在的“平台管理身份验证”，无法明确恢复。

- 改为说明实际的业主会话问题。仅 `401 UNAUTHENTICATED` 或 `403 FORBIDDEN` 显示“退出业主会话并刷新页面”；未知或不匹配的错误码、坏响应、501、503 和网络错误均不提供退出动作。
- 复用 C 既有退出组件和 `DELETE /api/auth/owner`，新增工单场景文案。只有用户点击后才退出，公共 `OwnerSessionState` 校验且收到 `live + signed_out` 后才刷新；等待中防重复、失败可重试，501 或 mock 回执不算成功。既有需求页保持原来的默认说明。
- 明确当前列表只包含固定 mock，不代表全站或当前业主的真实工单。退出不会取得平台管理权限或开放真实工单，服务方演示登录不受影响。结果以刷新后的公共接口为准，失败不补造空列表或模拟成功。
- 登录、退出或身份变化后提示重新加载；重载时旧列表和统计清除，成功响应保留来源标识。

## 文件与契约

修改 `src/features/c/AdminTickets.tsx`、`admin-tickets.ts`、`DemandAccessRecovery.tsx`，新增 `tests/C-admin-ticket-access.test.ts` 和本记录，共 5 个 C 文件。

继续使用公共 `Ticket`、`OwnerSessionState` 和 API 客户端。没有修改公共契约、API、认证逻辑、依赖或配置，没有新增运行时 mock。
