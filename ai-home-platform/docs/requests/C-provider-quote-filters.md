- 默认展示全部本人报价；可按公共 `Quote.status` 四种状态及报价/关联需求编号组合筛选。编号作字面部分匹配，不区分大小写，忽略输入首尾空白；不同字段不拼接，不搜索服务方或报价项目内容。
- 只筛选原有无参数 `GET /api/provider/quotes` 成功校验后的数据；切换条件不请求接口、不发送身份/搜索参数，不改变服务端授权范围、报价状态、记录顺序或原始金额。

- 刷新保留当前条件并使用新响应；加载及失败清除旧列表、统计及筛选结果。501 仍为失败，未命中的坏记录或重复编号也拒绝整份响应，不能靠筛选掩盖异常。

- 控件有明确标签和结果数量播报，支持键盘清除；沿用共享 UI，长报价编号允许换行。
