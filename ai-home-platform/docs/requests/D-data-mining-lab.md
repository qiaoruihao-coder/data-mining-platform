# 数据挖掘实验室设计

范围：在 D 归属路径新增 /mining，首页增加入口。中文热水器评论做二分类，美国 Vermont 服务方做聚类。保持原有匹配、报价和数据库契约。

离线 Python/scikit-learn 读取已核验数据，输出无原始评论及用户标识的聚合 JSON。Next.js 服务端页面直接读取生成结果，无需模型服务或 API key。页面展示真实数据来源、划分、基线、指标、混淆矩阵、簇数比较和群体特征。

分类在文本近重复分组后固定训练/验证/测试划分；仅验证集选择模型，不根据测试成绩调整。聚类探索 k=2..6，并报告随机种子稳定性。类别加数值画像是一项可验证的组合设计，不声称算法首创。

本阶段是离线实验结果接入，不提供在线输入评论实时预测，也不把研究商家纳入实际接单。验证包含划分完整性/无重叠、实验结果结构、项目 check/build、页面 HTTP 验收。
