# UI 改造记录（2026-11-18）

用户确认：温暖自然的家居杂志风，保留松绿品牌，使用桌面 ui设计 文件夹的两张照片。

## 行为变化
- 首页突出国内公开案例推荐；导航增加案例聚类、履约演示。
- 推荐页先展示国内真实案例，模拟施工队移入默认折叠 details；模拟统计设置也折叠。
- 新增 /demo 作为模拟匹配和报价的统一入口。
- /mining 展示六个群体的案例数、面积区间、风格和真实来源链接；实验参数表折叠可查看。
- 群体筛选改为直接读取实际存在的 cluster ID，避免依赖某个试验权重和簇数。

## 素材
public/images/home-editorial.jpg 与 home-detail.jpg 原样复制自用户提供的文件。未伪造为公开推荐案例的配图；页面标记用户提供及文件名中的设计工作室。现有数据源、账号、数据库不作替换。

## 验证
- Next.js 生产构建通过，lint/typecheck 通过。
- 浏览器 1440 桌面、390 手机检查：首页、案例推荐、聚类页面；群体 1 筛选返回对应两条案例，默认折叠模拟区域，登录状态保持。
- 手机页面整体未横向溢出，导航保持局部横向滚动。
- Impeccable detector 仅提示原有验收章 bounce-easing；属于此前既有交互，本次未改动。
- 旧空匹配测试更新为检查模拟区域，而非禁止整个页面包含真实案例。

涉及 D 公共页面与 B 推荐组件的跨模块改造，依据本轮用户对整体界面和信息架构的明确授权；不声称本轮仅限 D 文件。
