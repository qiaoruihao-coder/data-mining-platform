# 界面文案精简

按用户要求统一业主、服务方、运营端与公共页面文案。沿用 Impeccable clarify 的原则：一处表达一个意思，优先说操作与结果，保留决定所需信息。

- 删除重复解释，缩短宣传式标题；将开发用语改为用户用语。
- 模拟需求、模拟报价、模拟订单保留明确标签；live 记录称为“已保存”，不等同于真实交易。
- 单位改为“单价 / 元”等形式，选填和待确认说明去掉多余括号。
- 保留报价提交与接单的区别、未知费用、未保存内容丢失提示、访问权限与模拟交易说明。
- 不更改计算、认证、状态流转、数据内容和 API 契约。既有界面文字断言同步更新，行为断言保留。

本次跨 A/B/C 界面与共享组件的修改，由 D 按用户整站文案授权集成。
