# D：固定 mock 档期与报价、评价演示样例

2026-11-14，#141 已合入后，交付 B #133 交接中的下一块：冻结公共档期字段并在固定服务方目录提供可核对的 mock 样例，同步补齐截图要求的报价提醒和评价样本。本次提供共享契约、演示数据及必要的来源适配，不实现真实档期维护、预约锁定或 B 的排序接线。

## 公共字段

- `Provider.availability` 为可选对象或 `null`；缺省/null 表示未知，不等于确认没有档期。
- `windows` 是按 Asia/Shanghai 自然日解释的闭区间 `{ startDate, endDate }[]`，日期为有效 `YYYY-MM-DD`，按开始日期排序且不能重叠。
- `coverageStartDate` 与 `coverageEndDate` 说明本次查询覆盖范围，所有窗口必须落在范围内；空数组只表示该范围内没有已确认窗口。
- `updatedAt` 和 `validUntil` 是带时区的 ISO 8601 时间，更新时间不得晚于有效截止。契约不拿浏览器当前时间判断有效性，过期由调用方按读取时钟处理，以避免客户端时钟偏差影响解析。
- `source` 必须为 `mock` 或 `live`。本次固定样例全部为 `mock`；`null` 表示没有可靠样例。

## 固定样例

`GET /api/provider` 继续返回原六个固定演示服务方，基础资料和档期均明确标记为 mock。provider-a 有 2026-11-20 至 2026-12-20 的 31 天连续窗口，provider-b 有两段不重叠的 13/16 天窗口，provider-c 和 provider-f 有单段窗口，provider-d 在覆盖区间内明确为空窗口，provider-e 为未知 `null`。这些日期只是演示资料，不代表服务方承诺、预约成功或生产产能。

当前样例覆盖 `2026-11-15` 至 `2026-12-31`，固定更新时间为 `2026-11-14T00:00:00.000Z`，有效截止为 `2026-12-31T23:59:59.000Z`。到期后页面应显示“档期待更新”，不能继续参与档期排序；真实维护和更新入口尚未实现。
