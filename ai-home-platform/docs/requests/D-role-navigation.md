# 三端导航与路演账号说明

用户明确要求修复身份切换后正文页面未更新，并解释三端账号入口。本次修改共享导航及业主登录说明，单独以 D 分支交付；不修改认证接口、公共契约、数据库或依赖。

## 行为

- 切换业主、服务方、平台运营分别跳转 `/owner`、`/provider`、`/admin`，正文和导航一起切换。
- 当前角色直接由路径决定，刷新、浏览器前进/后退、直接打开深层链接时保持一致；路由切换期间显示状态并暂时禁用选择框。
- 新用户看到“可先体验需求澄清，发布需求需登录；暂未开放注册，向演示负责人领取账号”的说明。
- 切换页面不创建、撤销或替换任何登录会话。两种会话仍按现有接口优先级处理；不会因选择运营身份而授予管理员权限。

## 三端路演入口

| 端 | 当前账号方式 | 新用户路径 |
| --- | --- | --- |
| 业主 | 无默认账号密码；种子 demo-owner 没有密码凭证，不能登录 | 可匿名体验澄清；发布需维护者在对应数据库执行 npm run owner:create，交互开通账号 |
| 服务方 | 开启 DEMO_AUTH_ENABLED 后点击演示服务方登录，以 provider-a 建立模拟会话，无需输入密码 | 无公开注册；仅路演演示身份，不是生产服务方认证 |
| 平台运营 | 当前未实现管理员登录账号 | 可查看现有演示页面，不代表拥有生产管理权限 |

2026-11-15 只读核对当前 3000 预览使用的 a-preview-20261115.db：业主密码凭证记录为 0，并不存在可交付的原有业主密码。没有读取密码哈希、创建默认密码或改变已有账号。
